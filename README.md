Sistema de Registro y Matrícula de Alumnos

Proyecto desarrollado para el curso **Algoritmos y Estructura de Datos** del IES Privado CIBERTEC.

Descripción

El sistema permite administrar el registro y la matrícula de alumnos en una entidad educativa. La aplicación será desarrollada en Java aplicando programación orientada a objetos, estructuras de datos y una interfaz gráfica.

Objetivo

Desarrollar una aplicación que permita gestionar alumnos, cursos, matrículas y retiros de forma organizada, aplicando conceptos de algoritmos y estructuras de datos.

Funcionalidades

El sistema contará con los siguientes módulos:

Mantenimiento

- Registrar alumnos.
- Consultar alumnos.
- Modificar los datos de los alumnos.
- Eliminar alumnos según su estado.
- Registrar cursos.
- Consultar cursos.
- Modificar cursos.
- Eliminar cursos según las matrículas existentes.
- Validar códigos y datos repetidos.

Registro

- Registrar matrículas.
- Generar números correlativos de matrícula.
- Registrar automáticamente la fecha y hora.
- Cambiar el estado del alumno a matriculado.
- Registrar retiros.
- Cambiar el estado del alumno a retirado.
- Cancelar matrículas y retiros según las reglas del sistema.

Consulta

- Consultar alumnos por código.
- Consultar cursos por código.
- Consultar matrículas por número.
- Consultar retiros por número.
- Mostrar los datos relacionados del alumno y del curso.

Reportes

- Alumnos con matrícula pendiente.
- Alumnos con matrícula vigente.
- Alumnos matriculados por curso.

Clases principales

El proyecto utilizará las siguientes clases:

- `Alumno`
- `Curso`
- `Matricula`
- `Retiro`

Estados del alumno

| Código | Estado |
|---|---|
| 0 | Registrado |
| 1 | Matriculado |
| 2 | Retirado |
